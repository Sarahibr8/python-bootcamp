Lab - Project Setup Script
• Create an entire project with one command.
• PowerShell Version
• Create folders
• Create virtual environment
• Install requests
• Initialize Git
• Display completion message


# Create Project Folder
mkdir MyProject

# Enter Project Folder
cd MyProject

# Create Folders
mkdir src
mkdir tests
mkdir docs

# Create Virtual Environment
python -m venv venv

# Activate Virtual Environment
.\venv\Scripts\activate

# Install Requests Package
pip install requests

# Save Requirements
pip freeze > requirements.txt

# Initialize Git
git init

# Add Files
git add .

# Create Initial Commit
git commit -m "Initial project setup"
